## SEO Opportunity Pipeline

### Data Sources

1. **Google Search Console API** — Search performance data
2. **Self-hosted Analytics** — Product usage data
3. **Sitemap Audit** — Indexability verification
4. **Manual Inspection** — Quality assurance

### Opportunity Types

| Type | Description | Priority | Effort |
|------|-------------|----------|--------|
| High impressions / weak CTR | Title/description optimization | High | Low |
| Positions 4-15 | Quick wins with internal linking | High | Low |
| Rising queries | New content opportunities | Medium | Medium |
| Declining winners | Refresh/update needed | Medium | Medium |
| Cannibalization | Consolidate/redirect | Medium | High |
| Legacy URLs | Redirect cleanup | Low | Low |
| Weak internal linking | Add contextual links | Medium | Low |
| Content/tool mismatch | Align content with intent | High | Medium |

## Measurable Hypotheses

For each SEO change, document:

1. **Query intent**: What is the user actually looking for?
2. **Current page**: What does the site currently show?
3. **Defect/opportunity**: What's wrong or could be better?
4. **Proposed change**: Specific modification
5. **Measurable hypothesis**: "Changing X will improve Y by Z% within N days"

### Example

**Query**: "تبدیل آدرس فارسی به انگلیسی"  
**Current page**: `/text-tools/address-fa-to-en`  
**Defect**: Meta description is generic, doesn't mention "۳ ثانیه"  
**Proposed change**: Update meta description to include speed benefit  
**Hypothesis**: Changing meta description will improve CTR from 30% to 35% within 14 days

## On-Page SEO Checklist

For each tool page:

- [ ] Title: "{Tool Name} رایگان آنلاین | جعبه ابزار فارسی" (50-60 chars)
- [ ] Description: "{Benefit} در {time}. بدون ثبت‌نام. پردازش محلی." (150-160 chars)
- [ ] H1: "{Tool Name}" (unique, descriptive)
- [ ] Intro: Clear explanation of what the tool does
- [ ] FAQ: 2-3 relevant questions with answers
- [ ] Schema: SoftwareApplication + FAQ
- [ ] Internal links: 3-5 related tools
- [ ] CTA: Clear call to action
- [ ] Trust copy: "پردازش محلی" where applicable

## Technical SEO

### Sitemap

- Location: `/sitemap.xml`
- Generated by: `app/sitemap.ts`
- Revalidate: 300 seconds (5 minutes)
- Includes: All indexable tools, blog posts, categories, guides

### Robots.txt

- Location: `/robots.txt`
- Generated by: `app/robots.ts`
- Allows: All public pages
- Disallows: `/admin/`, `/auth/`, `/api/`, `/checkout/`, `/search?`

### Canonical URLs

- Generated by: `lib/seo.ts` → `buildMetadata()`
- Format: `{siteUrl}{path}`
- Implementation: `<link rel="canonical" href="..." />`

### Structured Data

- **SoftwareApplication**: On every tool page
- **FAQPage**: On tool pages with FAQ section
- **Article**: On blog posts
- **Organization**: On homepage
- **WebSite**: On homepage with SearchAction

## Internal Linking Strategy

### From Blog to Tools

Every blog post should link to 2-3 relevant tools in the intro or conclusion.

### From Tools to Related Tools

Every tool page shows 6 related tools in the "ابزارهای مرتبط" section.

### From Category Pages

Each category page links to all tools in that category.

### From Homepage

Homepage links to top tools via:
- Hero quick links
- Category cards
- Use case sections
- Audience tracks

## SEO Monitoring

### Weekly Checks

1. **GSC Performance**: Clicks, impressions, CTR, position
2. **Index Coverage**: Errors, warnings, valid pages
3. **Sitemap Status**: Submitted vs indexed
4. **Core Web Vitals**: LCP, FID, CLS

### Monthly Checks

1. **Canonical Audit**: Verify all pages have correct canonical
2. **Redirect Audit**: Check for redirect chains
3. **Schema Validation**: Test structured data
4. **Content Audit**: Identify thin or outdated content
