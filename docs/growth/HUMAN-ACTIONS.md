## Actions That Cannot Be Automated

### A. Generate Rose Videos in Google Flow

**What**: Use the provided Google Flow prompts to generate 8-10 second Rose Reels.  
**Why**: Google Flow requires human interaction to generate video content.  
**When**: Before publishing each day's Reel.  
**Where**: Google Flow UI.  
**How**: Copy the prompt from the production kit → paste into Flow → generate → review → export.

### B. Publish to Rose Instagram Account

**What**: Upload and publish the generated Reel to the existing Rose Instagram account.  
**Why**: Instagram API access is not available for automated publishing.  
**When**: After generating and reviewing the Reel.  
**Where**: Instagram app or Creator Studio.  
**How**: Upload Reel → paste caption from production kit → add hashtags → publish.

### C. Record Instagram Insights (24h/72h)

**What**: Check Instagram Insights after 24h and 72h for each published Reel.  
**Why**: Instagram Insights requires manual access.  
**When**: 24h and 72h after publishing.  
**Where**: Instagram app → Insights → Content.  
**How**: Record: reach, impressions, saves, shares, comments, link clicks. Report back to the agent for analysis.

### D. Respond to Instagram Comments

**What**: Reply to comments on published Reels within 1 hour.  
**Why**: Comment engagement requires human interaction.  
**When**: Continuously after publishing.  
**Where**: Instagram app.  
**How**: Check comments → respond helpfully → direct to link in bio when appropriate.
