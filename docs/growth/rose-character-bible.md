## Content Style

### Reels (8-10 seconds)

```
Hook (0-2s): Strong problem statement
Tension (2-5s): Mistake, confusion, or pain point
Solution (5-8s): Tool demonstration or quick fix
CTA (8-10s): Clear next action
```

### Carousels

- Step-by-step tutorials
- Mistake comparisons
- Before/after transformations
- Quick tips and tricks
- Tool feature highlights

### Stories

- Behind-the-scenes
- Quick tips

1. Always use the immutable character block
2. Only modify variable blocks (outfit, environment, pose)
3. Keep dialogue in Iranian Persian
4. Maintain the 8-10 second structure for Reels
5. Include exactly one CTA per Reel
