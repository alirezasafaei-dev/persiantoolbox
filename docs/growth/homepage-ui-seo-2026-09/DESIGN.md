# طرح تأییدشده — ارتقای محدود

## هدف
صفحه اصلی باید حرفه‌ای‌تر و به‌یادماندنی‌تر باشد و کاربر ابزار مناسب را سریع‌تر پیدا کند. حفظ عملکرد پروداکشن و هزینه پایین تغییر شرط اصلی است.
مالک در ۲۰۲۶-۰۹-۲۰ جهت «آبی فعلی + فیروزه‌ای محدود، ارتقای هیرو و کارت‌ها» را تأیید و اجرای آن را به Codex CLI سپرد.

## زبان بصری
| نقش | رنگ پیشنهادی | کاربرد |
| --- | --- | --- |
| اقدام اصلی | #2563EB | CTA و focus؛ حفظ خانواده آبی فعلی |
| تأکید محدود | #0F766E | آیکون کاربردی و نشانه اعتماد |
| متن | #0F172A | حالت روشن؛ در dark از توکن مناسب استفاده شود |
| زمینه | #F8FAFC | سطح روشن آرام |
| کارت | #FFFFFF | تمایز با زمینه |

این‌ها جهت طراحی‌اند؛ توکن موجود در صورت نزدیک‌بودن حفظ شود. رنگ نهایی باید کنتراست متن عادی 4.5:1 و متن بزرگ/کنترل ضروری 3:1 را پاس کند. رنگ به‌تنهایی معنی منتقل نکند. اثر روانشناختی یا افزایش conversion بدون داده ادعا نشود.

## هیرو
- حفظ H1 فعلی، جستجو، href دکمه‌ها، quick links و شمارش داینامیک ابزارها.
- کادر جستجو واضح‌تر؛ توضیح با طول خط مناسب و فضای عمودی متعادل.
- شعاع گوشه هماهنگ با کارت‌ها و تزئین هندسی آرام در حاشیه، فقط CSS یا SVG سبک، aria-hidden و بدون گرفتن pointer.
- سه نشان اعتماد به‌صورت ردیف مرکزی wrap شوند؛ از تعداد ستون ثابت نامتناسب پرهیز شود.
- هیچ عکس تزئینی بزرگ، ویدئو، canvas، Three.js یا وابستگی انیمیشن اضافه نشود.

## کارت‌ها
- استفاده از آیکون‌های موجود، سطح رنگی ملایم و تمایز واضح عنوان و توضیح.
- hover/focus کوتاه 120 تا 180 میلی‌ثانیه، بدون تغییر ابعاد و جابه‌جایی محتوا؛ در reduced motion حرکت حذف شود.
- بخش‌ها و anchorهای اصلی در این مرحله حذف یا جابه‌جا نشوند.
- استایل با CSS module صفحه اصلی یا کلاس کاملاً scoped اجرا شود. توکن‌های سراسری سایر ابزارها تغییر نکنند.

## SEO و اعتماد
- BRAND در lib/brand.ts منبع نشانی برند است؛ Organization/WebSite یک مرجع ثابت با @id داشته باشند. CollectionPage/FAQ/ItemList صفحه اصلی باقی بمانند.
- sameAs فقط منابع تأییدشده؛ حساب اجتماعی جدید حدس زده نشود. نشانی قدیمی GitHub حذف/تصحیح شود.
- ادعای محلی‌بودن با /trust و رفتار واقعی ابزارها یکسان شود؛ توضیح پیشنهادی: «بسیاری از ابزارها در مرورگر شما اجرا می‌شوند؛ جزئیات پردازش و ارسال داده در صفحه شفافیت فنی آمده است.»
- metadata و JSON-LD با محتوای قابل مشاهده تطابق داشته باشند. noindex، canonical، robots و sitemap تغییر جمعی نکنند.
- robots/fonts فقط بعد از اثبات نیاز رندر و با diff مستقل بررسی شود.

## خارج از دامنه نخست
تغییر URL، حذف محتوای SEO، بازنویسی ابزار/محاسبه/پرداخت، مهاجرت DB، تغییر analytics consent، ساخت داشبورد، تولید انبوه مقاله، انتشار خودکار، تغییر زیرساخت و ساخت llms.txt صرفاً برای ادعای GEO.
هم‌پوشانی اعلان‌ها مستند شود؛ زمان‌بندی جدید اعلان نصب نیازمند تأیید مستقل مالک است.

## پذیرش
نمای 360، 390، 768 و 1440 پیکسل؛ حالت روشن/تاریک؛ بزرگ‌نمایی 200٪؛ صفحه‌کلید و reduced motion.
بدون overflow افقی، محتوای بریده، CTA مسدود، افزایش قابل‌توجه JS یا جهش چیدمان.
اسکرین‌شات قبل/بعد در اندازه و شرایط یکسان و بدون داده شخصی تهیه شود. زیبایی را با عدد ساختگی گزارش نکن.
