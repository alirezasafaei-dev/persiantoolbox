# PersianToolbox: ارتقای محدود صفحه اصلی و SEO/GEO

وضعیت: جهت طراحی در ۲۰۲۶-۰۹-۲۰ توسط مالک تأیید شد. این بسته، دستور کار اجرایی Codex CLI است؛ هنوز پیاده‌سازی یا استقرار انجام نشده است.

## نقش‌ها و اختیار
- مالک: علیرضا؛ تأیید نهایی ظاهر، ادغام و استقرار.
- ChatGPT: مدیر پروژه و مسئول جهت طراحی، اولویت‌ها و بازبینی شواهد.
- Codex CLI: مجری؛ بررسی کد، پیاده‌سازی، تست، commit و PR و گزارش شواهد.
- تصمیم‌های عادی پیاده‌سازی را مجری می‌گیرد. تغییر دامنه یا معماری را همراه گزینه پیشنهادی به مدیر پروژه گزارش می‌کند.
- این نقش‌ها سامانه خودکار تبادل پیام نیستند؛ گزارش Codex را مالک به همین گفت‌وگو برمی‌گرداند.
- اجازه اجرای کار محلی و ساخت PR وجود دارد. merge، استقرار staging/production و تغییر تنظیمات حساب GSC نیازمند دستور صریح مالک است.

## دامنه بسته
کار تأییدشده: آبی فعلی + فیروزه‌ای محدود، ارتقای هیرو و کارت‌ها، اصلاح ناسازگاری هویت schema و ادعاهای حریم خصوصی، بررسی رندر و SEO، و آماده‌سازی تحلیل GSC/GEO.
مرز: URLها، جریان ابزارها، قیمت‌گذاری، پرداخت، داده‌ها و زیرساخت استقرار حفظ شوند. بازطراحی گسترده، حذف بخش‌های ایندکس‌پذیر و وابستگی گرافیکی جدید داخل این مرحله نیست.
تغییر زمان‌بندی اعلان نصب یک تسک رفتاری مستقل است: ابتدا علت را بازتولید کن؛ فقط در صورت تأیید مالک آن تسک را پیاده‌سازی کن. این محدودیت نباید سایر تسک‌ها را متوقف کند.
