# تصویرساز فارسی: وضعیت آماده‌سازی انتشار

کاربر متن فارسی یا انگلیسی را در پرشین تولباکس وارد می‌کند و بدون ساخت حساب در سایت دیگری، نتیجه را همین‌جا می‌بیند و دانلود می‌کند. اتصال فعلی از فرم عادی FlatAI استفاده می‌کند؛ API رسمی نیست. درخواست با IP سرویس تصویرساز ارسال می‌شود، نه IP کاربر. این سرویس از چت و Cloudflare جداست.

## پیاده‌سازی

- رابط فارسی و API در Next.js؛ صف پایدار PostgreSQL و ذخیره موقت رمزگذاری‌شده.
- کنترل مالکیت درخواست، Origin، حجم ورودی، رضایت کاربر و سقف مصرف.
- لغو درخواست، بازیابی وضعیت پس از refresh، دانلود و نمایش خطاهای قابل فهم.
- توقف در CAPTCHA، نیاز به حساب یا محدودیت ارائه‌دهنده؛ بدون ارسال مجدد خودکار پس از restart.
- سه سرویس مجزا برای صف، مرورگر و خروجی اینترنت. مرورگر اطلاعات اتصال پایگاه داده را دریافت نمی‌کند. پراکسی فقط اتصال HTTPS به دامنه‌های مجاز FlatAI و IP عمومی تأییدشده را می‌پذیرد.
- پاک‌سازی هنگام فعالیت worker انجام می‌شود. انقضای دسترسی با حذف فیزیکی، نسخه پشتیبان و نگهداری ارائه‌دهنده یکسان نیست؛ سیاست حریم خصوصی این تفاوت را توضیح می‌دهد.

## شواهد تأییدشده — ۲۰۲۶/۱۰/۱۳

PR شمارهٔ ۲۲۹ ادغام شد و نسخهٔ `962ec6857a586ba4550a21f488a178a0b1c9c092` از مسیر رسمی blue-green روی سایت مستقر شد؛ در مرحلهٔ اول تصویرساز خاموش ماند. ۱۸۹۲ تست در ۲۵۴ فایل، بررسی قراردادها، ساخت و smoke نسخهٔ standalone پاس شدند. هر ۱۶ بررسی CI مربوط به commit اصلی نیز موفق بود.

آزمون واقعی روی میزبان تصویر، درخواست فارسی را از صف به تصویر قابل نمایش و دانلود تبدیل کرد؛ یک تولید اندازه‌گیری‌شده ۴۳۸ ثانیه طول کشید. refresh همان درخواست را بازیابی کرد و دانلود مجدد همان hash را داشت. sandbox، جداسازی شبکه، راه‌اندازی سرد، reload محافظت‌شدهٔ فایروال، restart Docker و ارتباط TLS ایران–میزبان تصویر نیز آزموده شدند. آزمون‌های قبلی شامل موفقیت کوتاه‌تر و timeout بوده‌اند؛ زمان پاسخ ثابت یا ظرفیت عمومی تضمین نشده است.

## وضعیت انتشار

پیش‌فرض کد خاموش است؛ با مجوز صاحب پروژه، عرضهٔ آزمایشی محدود در production فعال شد. یک درخواست واقعی از دامنهٔ اصلی در حدود ۹۷ ثانیه به تصویر JPEG با ابعاد ۸۳۲×۸۳۲ رسید. بازیابی پس از refresh، نمایش و دانلود واقعی، مالکیت درخواست و عدم ذخیره در cache پاس شدند. متن پردازش‌شده از صف پاک شد و دسترسی به نتیجه ۳۰ دقیقه است.

سقف فعلی: یک پردازش هم‌زمان، حداکثر سه درخواست منتظر، سه درخواست برای هر IP/مهمان در ساعت، ده درخواست در ساعت و بیست درخواست در روز برای کل سرویس. این‌ها سقف برنامه‌اند، نه سهمیهٔ تضمین‌شدهٔ FlatAI. پایش پنج‌دقیقه‌ای سلامت و نزدیک‌شدن انقضای گواهی نصب شده؛ تمدید گواهی و رسیدگی به خطاها همچنان مسئولیت اپراتور است. جزئیات در [بستهٔ انتشار](../ops/image-generation-release-checklist.md) آمده‌اند.

تنظیمات، آزمون‌های لازم، محدودیت نگهداری و rollback در [راهنمای عملیات](../ops/image-generation-runbook.md) آمده‌اند. مجوز این نوع استفاده چندکاربره در مستندات API رسمی FlatAI مشخص نشده است؛ بررسی آن با ارائه‌دهنده پیش از عرضه عمومی توصیه می‌شود. انتشار روی سرور همچنان تابع قاعده تأیید صریح در AGENTS.md است.
