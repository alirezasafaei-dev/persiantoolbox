# تصویرساز فارسی: وضعیت آماده‌سازی انتشار

کاربر متن فارسی یا انگلیسی را در پرشین تولباکس وارد می‌کند و بدون ساخت حساب در سایت دیگری، نتیجه را همین‌جا می‌بیند و دانلود می‌کند. اتصال فعلی از فرم عادی FlatAI استفاده می‌کند؛ API رسمی نیست. درخواست با IP سرویس تصویرساز ارسال می‌شود، نه IP کاربر. این سرویس از چت و Cloudflare جداست.

## پیاده‌سازی

- رابط فارسی و API در Next.js؛ صف پایدار PostgreSQL و ذخیره موقت رمزگذاری‌شده.
- کنترل مالکیت درخواست، Origin، حجم ورودی، رضایت کاربر و سقف مصرف.
- لغو درخواست، بازیابی وضعیت پس از refresh، دانلود و نمایش خطاهای قابل فهم.
- توقف در CAPTCHA، نیاز به حساب یا محدودیت ارائه‌دهنده؛ بدون ارسال مجدد خودکار پس از restart.
- سه سرویس مجزا برای صف، مرورگر و خروجی اینترنت. مرورگر اطلاعات اتصال پایگاه داده را دریافت نمی‌کند. پراکسی فقط اتصال HTTPS به دامنه‌های مجاز FlatAI و IP عمومی تأییدشده را می‌پذیرد.
- پاک‌سازی هنگام فعالیت worker انجام می‌شود. انقضای دسترسی با حذف فیزیکی، نسخه پشتیبان و نگهداری ارائه‌دهنده یکسان نیست؛ سیاست حریم خصوصی این تفاوت را توضیح می‌دهد.

## شواهد محلی

۱۷۰۸ تست اصلی پروژه پاس شده‌اند. تست‌های PostgreSQL، فرم مرورگر، ارتباط داخلی و خروجی شبکه نیز در مجموعه جداگانه اجرا می‌شوند. typecheck، lint، ساخت نسخه پروداکشن و اسکن امنیتی اجرا شده‌اند؛ نتیجه نهایی دقیق در گزارش پایان کار اعلام می‌شود. اجرای CI میزبانی‌شده هنوز تأیید نشده است.

در تست واقعی، یک درخواست فارسی حدود ۴۰ ثانیه بعد به تصویر قابل نمایش و دانلود تبدیل شد. درخواست بعدی حدود ۵۵۰ ثانیه منتظر ماند و با خطای زمان‌انتظار تمام شد. بازیابی درخواست با refresh و نمایش خطا در نسخه standalone هم بررسی شد. این شواهد، زمان پاسخ ثابت یا پایداری FlatAI را تضمین نمی‌کنند.

## وضعیت انتشار

فعال‌سازی عمومی به صورت پیش‌فرض خاموش است. ساخت کانتینر، sandbox و جداسازی شبکه روی Linux، دسترسی واقعی با IP میزبان و ظرفیت عملی هنوز تأیید نشده‌اند. آماده‌بودن کد برای بررسی، به معنی آماده‌بودن سرویس برای کاربران عمومی نیست.

تنظیمات، آزمون‌های لازم، محدودیت نگهداری و rollback در [راهنمای عملیات](../ops/image-generation-runbook.md) آمده‌اند. مجوز این نوع استفاده چندکاربره در مستندات API رسمی FlatAI مشخص نشده است؛ بررسی آن با ارائه‌دهنده پیش از عرضه عمومی توصیه می‌شود. انتشار روی سرور همچنان تابع قاعده تأیید صریح در AGENTS.md است.
