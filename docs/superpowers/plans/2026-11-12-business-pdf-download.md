# Business PDF download repair

## Verified defect

DocumentStudio calls downloadPdf(html, filename). The helper resolves before the deferred window.print call and resolves when window.open returns null. The paid caller confirms its reservation after that resolution, so confirmation does not prove even a print dialog opened.

## Implementation design

Generate a real PDF Blob locally from BusinessDocumentDraft and computed BusinessDocumentTotals. Reuse pdf-lib, the existing composite Persian font/shaping implementation and same-origin Vazirmatn fonts; add no dependencies. Keep the explicit Print action separate. After byte generation succeeds, initiate the browser file download; only then may the caller confirm. Font/generation/download errors must reject and cancel the reservation through the existing handler. Do not claim the browser can prove the user retained a file on disk.

Preserve seller/buyer fields, date/number, all six item columns, totals, notes, footer, disclaimer, watermark and logo. Handle long text and multipage tables, repeat column headings, and reject unsupported logo types rather than silently omitting them. Do not upload document content. Do not change credit limits or premium entitlements.

Alternatives considered: waiting for afterprint cannot distinguish Save from Cancel; opening a popup earlier fixes popup blockers but still cannot establish a PDF was created. Neither closes the actual defect.

## Acceptance

1. Actual generated bytes load as PDF and contain selectable/searchable Persian and Latin text.
2. Invoice/proforma/receipt, all optional party fields, logo and watermark are preserved.
3. Long descriptions, notes and many rows fit and paginate without overlapping footers.
4. Font/generation failure refunds the reservation and never confirms export; duplicate clicks do not consume duplicate credits.
5. Browser download event is a PDF file, without a print popup. Local synthetic tests do not consume production credits.
6. Focused and full gates, actual PDF render, independent review and exact-head hosted checks before requesting separate merge/deploy approval.
